KROMA documentation

Ontology matching with retrieval and language models

KROMA aligns concepts across two ontologies. It retrieves nearby labels, asks a model if the pair matches, and refines the joined graph.

Get started Read the paper 
$ git clone https://github.com/lamng3/kroma.git
cd kroma
./setup.sh
source .venv/bin/activate
$ kroma --help
$ kroma run --method_config kroma_scibert_envo_sweet \
  --llm meta-llama/Llama-3.3-70B-Instruct-Turbo-Free --baseline

Paper

arXiv:2507.14032 is the public paper. The full PDF shipped with this repository is full.pdf at the repository root.

Workflow

Load

Read alignment CSVs and cached concept dictionaries.

Retrieve

Combine SciBERT text with Node2Vec structure.

Judge

Ask one model, or a debate of models, for yes or no.

Refine

Update the joined graph online, then collapse it offline.
