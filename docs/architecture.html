Guide 02

Architecture

One run loads a method config, scores alignment pairs, and writes predictions.

Config

kroma run reads a method JSONL and the dataset JSON it names.

Task

CSV rows become source and target graphs plus a sampled alignment list.

Index

SciBERT and Node2Vec vectors fill two in-memory stores.

Decision

A single model or a debate returns yes or no and a confidence.

Package

Installable code lives in src/kroma/. Experiment configs stay in experiments/ and are not imported as a library.

ModuleRole
cliRunCommand parses flags and starts a run.
pipelineMatchingRun prepares, scores, and writes metrics.
tasksLoaders, prompt builders, and query strategies.
agentsSingle-model and debate inference.
inferenceFactory for chat and embedding backends.
algorithmsNode2Vec fusion and online or offline refinement.
repositoryPrediction JSONL and expert-review CSV.

Extension points

  • register_chat_backend and register_embedding_backend add model providers.
  • register_query_strategy adds a context source such as a dictionary or SPARQL endpoint.
  • OntologyLoader is the base for a new alignment file format.
  • InferenceStrategy is the base for a new judging procedure.
