kroma.cli

RunCommand

The command that starts one experiment from parsed arguments.

RunCommand(args).execute() -> None
kroma run \
  --method_config kroma_scibert_envo_sweet \
  --llm meta-llama/Llama-3.3-70B-Instruct-Turbo-Free \
  --baseline

--debate is a boolean flag. Omit it for a single model.

kroma.pipeline

MatchingRun

Template for a run: prepare the task, score pairs, then write metrics.

MatchingRun(args, listener=None)
MatchingRun.execute() -> dict
MethodPurpose
prepare()Load configs, build the task, and fill the vector stores.
score_pairs()Judge each alignment and record the prediction.
finish()Run the final offline refinement and write the metrics JSON.

MetricsListener collects token counts and refinement timings for that run.

kroma.inference

Model factory

Chat providers adapt OpenAI and Together through one response parser. Embedding providers adapt Hugging Face and sentence-transformers.

create_inference_model(backend, model_name) -> BaseModel
create_embedding_model(backend, model_name) -> BaseEmbeddingModel
register_chat_backend(name, provider_cls) -> None
register_embedding_backend(name, provider_cls) -> None

BaseModel.generate retries transient connection, timeout, and rate-limit errors.

ClassRole
SingleModelInferenceOne agent, one round.
DebateInferenceOne agent per config, for the configured number of rounds.
