Guide 01

Getting started

Install the package, point it at a dataset, and run one configured experiment.

Install

git clone https://github.com/lamng3/kroma.git
cd kroma
./setup.sh
source .venv/bin/activate
kroma --help

kroma --help does not download a model. A matching run needs the model extra:

uv pip install ".[models]"

API keys

Copy .env.example to .env. Together models read TOGETHERAI_API_KEY. OpenAI models read OPENAI_API_KEY.

Datasets

Put alignment CSVs and dictionary JSONL files under experiments/dataset/. Dataset configs in experiments/configs/datasets/ name the CSV folder. experiments/configs/dictionary.json names each cache file. Those paths are gitignored because the benchmarks are downloaded separately.

Run

kroma run \
  --method_config kroma_scibert_envo_sweet \
  --llm meta-llama/Llama-3.3-70B-Instruct-Turbo-Free \
  --baseline

The same flags work as python -m main --method_config ....

Read the docs site

python -m http.server -d docs 8000

The full paper PDF is full.pdf in the repository root. The arXiv record is 2507.14032.
