ENVO-SWEET

scripts/run_envo_sweet.sh runs the Llama 3.3 70B baseline:

kroma run \
  --method_config kroma_scibert_envo_sweet \
  --llm meta-llama/Llama-3.3-70B-Instruct-Turbo-Free \
  --baseline

Method files live under experiments/configs/method/<llm>/. Add a model by adding a folder and a .jsonl file. Add a dataset by adding experiments/configs/datasets/<name>.json.

Outputs

  • results/baseline/<task>/ stores accepted prediction JSONL and a .metrics.json summary.
  • reviews/baseline/<task>/expert_queries.csv stores pairs sent for expert review.
  • logs/kroma.log stores the run log.

--size can be xsmall, small, medium, large, or full.
